# ROP Connect — beta wishlist (things Slack does that we could add)

Running list from testing. Format is deliberately copy‑paste‑ready — each item is written the
way Rob asked ("Hey, I liked in Slack when we could…") so it can be dropped straight into the AI.

## Candidates (not yet built)

1. Hey, I liked in Slack when I could hit **Cmd/Ctrl+K** (a "quick switcher") to jump to any
   channel or person by typing a few letters, instead of scrolling. Can we add that?

2. Hey, in Slack when someone was typing you'd see a **"…is typing"** indicator at the bottom.
   Let's add typing indicators in channels and DMs.

3. Hey, on the Slack phone app I could **swipe a message to reply** to it (and swipe the other way
   to react). Can we add swipe actions on messages on mobile?

4. Hey, in Slack you could **set a status** (an emoji + text like "🎨 With a client") that showed
   next to your name so people knew if you were busy. Let's add that.

5. Hey, in Slack I could **save/bookmark a message** to come back to it later, and see all my saved
   items in one place. Can we add "Save message"?

6. Hey, in Slack I could **schedule a message** to send later (write it now, it goes out at a set
   time). Useful for morning huddles. Let's add scheduled send.

7. Hey, in Slack, unsent text I typed in a channel was **saved as a draft** so I didn't lose it
   when I switched away. Let's keep drafts per channel.

8. Hey, in Slack I could type **@channel or @here** to notify everyone in a channel at once (for
   important posts). Can we add that (limited to leaders so it isn't abused)?

9. Hey, in Slack the emoji reaction picker had a **full searchable emoji list**, not just a few
   quick ones. Let's add a full emoji picker.

## Shipped (was on the list, now done)

- Long-press a message for an action sheet (react / reply / pin / edit / delete) — mobile. ✅
- Dedicated Channels tab + full-screen conversations with a back button — mobile. ✅
- Phone push notifications with per-channel mute. ✅
